# Prediction of Cardio Disease

A machine learning project that predicts the risk of 10-year coronary heart disease using patient health data.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Models

- Decision Tree
- Random Forest

## Project Features

- Data preprocessing
- Missing value handling
- Class imbalance handling
- Model training and evaluation
- Hyperparameter tuning
- Interactive prediction interface
